The Platform Modules

Portl features three tightly integrated products to digitalize all daily interactions.

Visitor Management

Bidirectional notification approval workflow under 30 seconds. Pre-approve guests, generate temporary QR passes, and maintain historical audit logs.

Guard Dashboard

Super-fast walk-in registration, barcode/QR scanning, and exit logging designed specifically for high-pressure security desks at the gate.

Resident Hub

A centralized interface for residents to approve entries, book amenities, pay monthly maintenance bills, raise complaints, and read announcements.

Amenity Booking

Admins can create amenities with hours, capacities, and slot durations. Residents reserve slots via real-time calendars with manual fee verification.

Notice Board & Polls

Broadcast critical updates to specific targets (Guards, Residents, or All) and launch opinion polls to replace chaotic WhatsApp voting lists.

Helpdesk & Complaints

Structured category categorization (Maintenance vs. Complaints), assigned staff notifications, status progression tracking, and inline comment threads.

System Architecture & Tech Stack

Portl runs on a monorepo workspace structured for scaling, speed, and real-time operations.

Monorepo Structure (Turborepo)

Code is split into discrete packages: apps/mobile, apps/api, and shared packages including client models and Zod schemas, minimizing duplication and enforcing type safety.

Frontend Stack

Built with Expo SDK 55 + React Native for cross-platform app performance, leveraging TanStack React Query for server-state caching and state synchronization.

Backend REST API

Powered by a robust NestJS REST API designed with strict TypeScript models, Zod validation pipelines, and dependency injection services.

Database & Push

A MongoDB database managed via Mongoose is paired with Firebase Cloud Messaging (FCM) to dispatch instant push notifications to mobile clients.
